### 👋 Bonjour, moi c'est GoldenDev74

Développeur togolais, j'aime **aller du composant à l'utilisateur** : programmer un microcontrôleur le matin,
livrer une application web l'après-midi et, en ce moment, bâtir un logiciel de bureau natif en C++.
Ce qui me motive : des outils **utiles, fiables et adaptés à notre réalité** — connexion intermittente,
formats administratifs locaux, données sensibles qui doivent rester sur le poste.

- 🔭 Je construis **Scella**, un éditeur PDF 100 % hors ligne pour les cabinets d'audit (Togo et France)
- 🛒 Je fais évoluer **[Naneu-shop](https://github.com/GoldenDev74/naneu-shop)**, une gestion de stock et de caisse pour commerces
- ⚡ J'aime l'électronique embarquée : microcontrôleurs, capteurs, IoT
- 🤝 Ouvert aux **missions freelance** et aux **collaborations** : web, mobile, desktop, IoT

### 🚀 Projet phare : Scella

> L'éditeur PDF des auditeurs : lire, annoter, **anonymiser** et **signer** des dossiers sensibles, sans qu'aucune donnée ne quitte le poste.

| | |
|---|---|
| 🕵️ **Anonymisation intelligente** | Détection hors ligne des données sensibles togolaises et françaises (NIF, RCCM, IBAN, CNI et MRZ, téléphones…), suppression réelle du texte, des métadonnées et du contenu caché |
| 🔎 **Reconnaissance de texte (OCR)** | 119 langues, écriture manuscrite lue par un second moteur (PP-OCRv5 / ONNX Runtime) |
| ✍️ **Tampons et signatures** | Tampons d'audit (VU, VÉRIFIÉ, CONFORME…), signature dessinée ou importée, incrustés dans la page ; signatures conservées chiffrées |
| 🧱 **Sous le capot** | C++23 · Qt 6 · MuPDF · SQLite · GoogleTest · CI GitHub Actions · installateur MSI (WiX) |

<sub>Code privé — produit en phase pilote.</sub>
